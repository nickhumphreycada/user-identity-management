## Web Architecture Explanation
When a user opens a web page, the browser sends an HTTP Request to the server, and the server processes it and returns an HTTP Response (like status 200 OK). Web communication is stateless, meaning the server forgets each request immediately after responding. Web apps use sessions and cookies to remember if a user is logged in.
